This folder holds the recompiled code, one file per game: Rom_<CRC32 of the ROM>.cs
They are created by   GenesisRecomp --recompile "game.bin"   (or build_port.cmd) and compiled into the program.
Delete a file here and rebuild to remove that game's recompiled code (the game then just runs through the interpreter).
The files are derived from the games' machine code: keep them for yourself, don't share them.
